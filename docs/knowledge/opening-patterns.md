# 珠型と開局の知識

## 珠型とは

連珠の最初の3手は配置が制限されている:

1. **黒1**: 天元（H8）に置く
2. **白2**: 天元の周囲1路以内（3x3中央）に置く
3. **黒3**: 天元の周囲2路以内（5x5中央）に置く

対称形を除くと26通りの形が存在し、これを**珠型（しゅけい）** と呼ぶ。白2の位置により「直打ち（縦横隣接）」と「間打ち（斜め隣接）」に大別される。

## 珠型の戦略的分類

### 黒必勝珠型

黒が正確に打てば必ず勝てることが解明されている珠型。直打ちでは寒星、渓月、花月、雨月、金星など多数。間打ちでは峡月、恒星、水月、雲月、浦月など。

**黒の戦略**: 定石手順に従い、正確に攻める。VCFやVCTの手順が確立されている。

### 白有利珠型

疎星（D3）、遊星（D13）、長星（I1）、流星（I5）、彗星（I13）など。

**白の戦略**: 黒の攻めを受け止めながら、禁手追い込みや白の三三・四四（白には禁手がない）で反撃する。

### 互角珠型

瑞星（D11）、松月（D8）、丘月（D9）など。

**戦略**: 両者ともミスが許されない精密な戦い。中盤の構想力が問われる。

## 開局の基本方針

### 黒（先手）の方針

1. **中央支配**: 天元周辺に石を集め、複数方向に展開できる形を作る
2. **活二の構築**: 活二（両端が空いた二連）を複数方向に作り、活三への発展を狙う
3. **禁手回避**: 三三禁・四四禁に注意しながら攻める
4. **山形の構築**: 石を山形（ピラミッド型）に組むと、複数方向に脅威を作りやすい

### 白（後手）の方針

1. **分断**: 黒の石のつながりを分断し、一方向に限定する
2. **禁手誘導**: 黒の禁手になる点を意識し、攻めの選択肢を制限する
3. **反撃準備**: 防御しながら自分の活二・活三を作り、カウンターアタックの基盤を築く
4. **白の特権活用**: 白には禁手がないため、三三・四四を自由に作れる利点を活かす

## 4手目以降の考え方

### 白4手目

- 黒3の方向に対して斜めに置くことが多い（黒の方向性を限定する）
- 黒の石を挟む位置に置き、分断を図る
- 自分の活二の基盤を作ることも重要

### 黒5手目

黒5手目は序盤で最も重要な手。ここで局面の性格が決まる。

- 必勝珠型や有利な珠型を選んだだけではいい形に組めない。5手目、7手目の打ち方が最も重要
- 向きが1路違うだけで結論がまったく変わることがある（必勝 vs 必敗）
- 序盤の必敗型は、だいたい三三禁を狙われるパターンがほとんど
- 黒は三三禁を見極めながら、地雷を避けるように打ち進めるのが肝心

### 組み立ての基本原則（京都連珠会の講座より）

1. **斜めの連を叩く**: 斜めの連は攻撃力が高いため、それを三にさせないのが主目的。叩く手は多くの場合、離れた連や剣先をつないでいる
2. **山形に組む**: 石を山形（ピラミッド型）に組むと、複数方向に脅威を作りやすい
3. **標準的な1局の流れ**:
   - 序盤で山形などのいい形に組む
   - 三を引いていく
   - ミセ手や含み手で決める

## CPUアルゴリズムへの示唆

### 現在の実装

- `src/logic/cpu/opening.ts` で珠型パターンをハードコード
- `JUSHU_EVALUATION` で珠型ごとの評価値を定義（未使用）
- 4手目以降はMinimax探索に移行

### 改善の方向性

1. **珠型別評価の活用**: 珠型に応じた序盤評価の重み付け
2. **定石データベース**: 主要珠型の定石手順（5-10手目）をデータベース化
3. **方針の切り替え**: 黒必勝珠型では攻撃的、白有利珠型では慎重な評価に切り替え
4. **白4手目の知識**: 各珠型に対する白の最善4手目のデータ
