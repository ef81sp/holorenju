# 珠型別定石

各珠型の定石（主要変化）をまとめたもの。座標は左下原点（H8が天元）。
棋譜は黒1(H8)→白2→黒3→白4→黒5→... の順。

> **注意**: 定石手順は「自由打ち」（5手目以降も自由に打てるルール）を前提としたものである。現代の公式戦では「多題打ち」等の開局規定により、必ずしもこれらの定石手順通りにはならない。しかし、序盤の基本的な考え方を理解するうえで定石の学習は不可欠である。

## 座標体系

- 天元: H8
- 列: A(左端)〜O(右端)
- 行: 1(下端)〜15(上端)
- 白2の位置で直打ち/間打ちに分類

## 直打ち珠型（白2が天元の縦横隣接）

以下は白2がH7（天元の下1路）に置かれた場合を基準に記述。他方向の場合は回転対称。

### 寒星（かんせい）D1

**黒3手目**: H6（白2と同方向にさらに1路）
**評価**: 黒必勝

黒3が白2の延長上にあり、黒が縦に連を伸ばしやすい形。

#### 変化1: 白4コスミ（I7）

棋譜: H8 H7 H6 I7 I6
ポイント: 黒5で山形に組む。斜めの連を作りやすく、黒が主導権を握る。

#### 変化2: 白4ツケ（I6）

棋譜: H8 H7 H6 I6 I7
ポイント: 黒5で白の斜め連を叩きつつ山形を構築。

---

### 渓月（けいげつ）D2

**黒3手目**: I6（白方向に2路・右1路）
**評価**: 黒必勝

黒3が白2の桂馬位置にあり、斜めの展開が豊富。

#### 変化1: 白4外ハネ（I7）

棋譜: H8 H7 I6 I7 H6
ポイント: 黒5で縦の連を作り、山形に発展させる。

#### 変化2: 白4コスミ（G7）

棋譜: H8 H7 I6 G7 I7
ポイント: 黒5で中央を確保し、多方向への展開を維持。

#### 参考

渓月は変化が豊富で、京都連珠会の河村九段による「渓月多題打ちの研究」（珠友311-313号）で詳しく解説されている。

---

### 疎星（そせい）D3

**黒3手目**: J6（白方向に2路・右2路）
**評価**: ほぼ互角（白やや有利）

黒3が天元から離れており、石の連携が弱い。直打ち珠型では珍しく白が有利な形。

#### 変化1: 白4ツケ（I7）

棋譜: H8 H7 J6 I7 I6
ポイント: 黒5で白に近い位置を確保するが、黒の石が分散しがちで白が受けやすい。

#### 参考

京都連珠会の「不思議珠型、疎星」（珠友347号）で詳しく解説されている。

---

### 花月（かげつ）D4

**黒3手目**: I7（白2の右隣接、天元の右下斜め）
**評価**: 黒必勝

最も研究された珠型の一つ。黒3が白2と天元の両方に斜めに接しており、山形に組みやすい。

#### 変化1: 切り違い（白4がG7）

棋譜: H8 H7 I7 G7 G6
ポイント: 黒5で白の斜め連を叩く。京都連珠会の講座で「斜めの連を叩く」典型例として紹介される定石。叩く手は離れた連や剣先をつないでいることが多い。

#### 変化2: 白4ハサミ（G9）

棋譜: H8 H7 I7 G9 I8
ポイント: 黒5で横の連を伸ばし、山形の形を目指す。

#### 変化3: 白4ツケ（I8）

棋譜: H8 H7 I7 I8 G7
ポイント: 黒5で白の斜め連を叩きつつ、自分の形を広げる。

#### 参考

- 花月は黒必勝の代表的珠型で、すべての白4に対して黒が勝てることが解明されている。
- 京都連珠会「花月は進化する？」（珠友282号）で近年の研究動向が解説されている。
- 花月と浦月は「山形に組みやすい」ことが黒必勝の最大の理由（京都連珠会初級講座第2回）。

## 定石の基本原則

### 序盤の組み立て（京都連珠会の講座より）

1. **山形に組む**: 石を山形（ピラミッド型）に配置すると、複数方向に二連を作れる。花月と浦月が必勝なのは「山形に組みやすい」ことが最大の理由。
2. **斜めの連を叩く**: 斜めの連は攻撃力が高いため、三にさせない。叩く手は多くの場合、離れた連や剣先をつないでいる。
3. **5手目の重要性**: 珠型選択だけではいい形に組めない。5手目・7手目の打ち方が最も重要。向きが1路違うだけで結論が必勝から必敗に変わることがある。
4. **三三禁の回避**: 序盤の必敗型はほとんどが三三禁を狙われるパターン。黒は三三禁を見極めながら地雷を避けるように打ち進める。
5. **広い方に三を引く**: 白の少ない（＝広い）方向に三を引くのが大原則。

### 珠型の戦略的分類

| 分類        | 珠型                                                                   |
| ----------- | ---------------------------------------------------------------------- |
| 黒必勝 (\*) | 寒星、渓月、花月、雨月、金星、峡月、恒星、水月、雲月、浦月、嵐月、明星 |
| 黒有利      | 残月、新月、山月、銀月、名月                                           |
| 黒やや有利  | 松月、丘月、瑞星、斜月                                                 |
| 白やや有利  | 疎星、長星、流星                                                       |
| 白必勝      | 遊星、彗星                                                             |

(\*) 「黒必勝」は Wikipedia "Renju opening pattern" の分類（自由打ちルール前提）に基づく。花月・浦月は必勝定石が最も整備されており、入門者でも手順通り打てば勝てる。他の珠型は解析上は黒必勝とされるが、実戦で必勝手順を実行するには高い棋力が必要。
