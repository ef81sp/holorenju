# パターン認識（連・跳び三・跳び四等）

## 基本パターン一覧

連珠では石の並び方を「連」と呼び、その形と開き具合によって脅威度が大きく異なる。

### 連続パターン

| 名称           | 形       | 脅威度 | 説明                                                   |
| -------------- | -------- | ------ | ------------------------------------------------------ |
| 五連           | `●●●●●`  | 勝利   | 5個連続で勝ち                                          |
| 活四（達四）   | `_●●●●_` | 最高   | 両端が空き。防御不可能                                 |
| 止め四         | `X●●●●_` | 高い   | 片端が塞がった四連。止められるが四追いの起点           |
| 活三           | `_●●●_`  | 高い   | 両端が空き。放置すると活四になる                       |
| 止め三（剣先） | `X●●●_`  | 低い   | 片端が塞がった三連。四追いのタネだが即座の脅威は少ない |
| 活二           | `_●●_`   | 中程度 | 両端が空き。将来の活三の基盤                           |
| 止め二         | `X●●_`   | 低い   | 片端が塞がった二連                                     |

※ `_` = 空き、`X` = 相手石または盤端

### 跳びパターン

1マス空いた形。連続パターンと同等の脅威を持つ重要なパターン。

| 名称     | 形       | 同等の脅威 | 説明               |
| -------- | -------- | ---------- | ------------------ |
| 跳び四   | `●●●_●`  | 止め四     | 空きを埋めると五連 |
| 跳び四   | `●●_●●`  | 止め四     | 空きを埋めると五連 |
| 跳び四   | `●_●●●`  | 止め四     | 空きを埋めると五連 |
| 活跳び三 | `_●●_●_` | 活三       | 空きを埋めると活四 |
| 活跳び三 | `_●_●●_` | 活三       | 空きを埋めると活四 |

### パターンの派生関係

```
活二 → 活三 → 活四 → 五連（勝ち）
  ↓       ↓       ↓
止め二  止め三  止め四 → 五連（相手が止めなければ）
                  ↑
              跳び四
```

## パターン認識の優先順位

局面を読む際、以下の順序でパターンを認識する:

1. **五連**: 即座に勝敗が決まる
2. **活四**: 防御不可能。次の手で五連確定
3. **止め四・跳び四**: 1手で止められるが、連続すれば（VCF）決め手
4. **活三・活跳び三**: 放置すると活四。必ず止める必要がある
5. **四三の同時脅威**: 四と活三が同時にできる点
6. **活二**: 将来の活三の基盤。攻めの準備
7. **止め三**: 四追いのタネ。即座の脅威は少ない

## 脅威の方向と複合

### 複数方向脅威

2方向以上で同時に脅威を作ると、相手は1つしか防御できない。

```
例: 縦と横に同時に活三

  F  G  H  I
9     ●
8  ●  *  ●     ← *に置くと縦横に活三
7     ●

→ 相手は縦か横のどちらかしか止められない
```

### 斜め方向の優位性

斜め方向の連は、縦横の連よりやや有利:

- 隣接する空き点が多い
- 複合脅威を作りやすい
- 人間にとって見落としやすい

## 止め三（剣先）の再評価

### 剣先の性質

止め三は「剣先」とも呼ばれ、四追い（VCF）のタネになる。ただし:

- 剣先自体は即座の脅威にはならない
- 活三を止められた副産物として自然にできることが多い
- わざわざ止め二から剣先を作る手はあまり有効でない

### 剣先が有効な場面

- 複数の剣先がVCF（四追い勝ち）を構成する場合
- フクミ手の一部として機能する場合
- 相手の活三を止めた結果できた剣先（副産物）

### AI評価での扱い

```
止め三: 30点（活二: 50点より低い）
→ 止め二から止め三を作るより、活二を発展させる方が有望
```

## 単発四の問題

### 単発四とは

四三にもVCFにも繋がらない、単独で打つ四のこと。

### なぜ悪手か

1. **攻撃リソースの浪費**: 四は本来トドメか連続攻撃に使うべき
2. **相手の石を増やす**: 防御で石を置かれ、相手の形が良くなることもある
3. **手番を失う**: 防御されると相手の手番

### 例外: 後続脅威がある四

四の後に次の四を作れる場合（VCFの一部）は有効。後続脅威の判定が重要。

## パターンの検出方法

### 方向走査

各方向（横、縦、右斜め、左斜め）の4方向について、石の並びをスキャンする。

```
4方向:
→ 横: (0, +1)
↓ 縦: (+1, 0)
↘ 右斜め: (+1, +1)
↗ 左斜め: (-1, +1)
```

### 連続パターンの検出

ある位置から方向に沿って石を数え、両端の空き状況を確認する。

```
検出手順:
1. 起点から正方向に自石を数える
2. 起点から逆方向に自石を数える
3. 合計の連続数を求める
4. 両端が空きか、片端が空きか、両端が塞がりかを判定
5. パターン（活四、止め四、活三、etc.）を分類
```

### 跳びパターンの検出

1マス空きを含むパターンの検出には、空きの位置も考慮する。

```
跳び四の検出:
- ●●●_● パターン: 3連 + 空き + 1石
- ●●_●● パターン: 2連 + 空き + 2連
- ●_●●● パターン: 1石 + 空き + 3連

跳び三の検出:
- _●●_●_ パターン: 空き + 2連 + 空き + 1石 + 空き
- _●_●●_ パターン: 空き + 1石 + 空き + 2連 + 空き
```

## 形の認識訓練

連珠が強い人は以下を速やかに認識・把握できる:

1. **四の位置**: 一手で勝てる場所
2. **三の位置**: 一手で四にできる場所
3. **ミセ手**: 一手で四三にできる場所
4. **フクミ手**: 一手でVCFが始まる場所

この認識能力を上げるには、四追い問題を繰り返し解くことが効果的。

1. **活二の方向性評価**: 活二が複数方向に揃っている場合のボーナス

4. **形の効率評価**: 少ない石数で多くのパターンを作る手を高評価
