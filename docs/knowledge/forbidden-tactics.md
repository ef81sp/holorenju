# 禁手を利用した白の戦術

## 概要

連珠では黒のみに禁手（三三禁、四四禁、長連禁）がある。白はこの非対称性を利用して、黒を禁手に追い込む戦術を持つ。「白を持ったら禁手を狙え」は連珠の有名な格言。

## 禁手の種類（復習）

| 禁手   | 条件                      | 例外                           |
| ------ | ------------------------- | ------------------------------ |
| 三三禁 | 活三を同時に2つ以上作る手 | 五連が作れる場合は禁手ではない |
| 四四禁 | 四を同時に2つ以上作る手   | 五連が作れる場合は禁手ではない |
| 長連禁 | 6個以上の石が連続する手   | なし（五連のみ有効）           |

**重要**: 白には禁手が一切ない。白は三三も四四も長連も自由に作れる。

## 禁手追い込みの基本パターン

### パターン1: 防御位置が禁手

白の四に対して、黒の唯一の防御位置が禁手点の場合、黒は防御できずに負ける。

```
盤面例: 白の四の防御位置が三三禁

  D  E  F  G  H  I  J
9           ●
8     ○  ○  ○  ○  _    ← 黒は J8 に置かねばならない
7           ●
6        ●
5

もし J8 が三三禁の点であれば:
→ 黒は J8 に置けない
→ 白の四を止められない
→ 白の勝ち
```

### パターン2: 禁手への誘導セットアップ

白が活三を伸ばして止め四にすると、黒の防御位置が禁手になるように仕組むパターン。

```
盤面例:
  E  F  G  H  I
8  _  ○  ○  ○  _    ← 白の活三

白が E8 に伸ばすと:
  E  F  G  H  I
8  ○  ○  ○  ○  _    ← 白の止め四

黒は I8 に置いて止めるしかないが、
I8 が禁手点なら → 白の勝ち
```

### パターン3: 四追いによる禁手追い込み

白がVCF（四追い）の途中で、黒の防御位置が禁手点になるように四を連打する。

```
VCF手順:
1. 白が四を作る → 黒が止める
2. 白が別の四を作る → 黒が止める
3. 白が四を作る → 黒の防御位置が三三禁点
→ 黒は防御できない → 白の勝ち
```

## 三三禁の利用

### 三三禁を作る仕掛け

白は黒の石の配置を観察し、三三禁が発生しやすい形を意図的に作る。「四つ目の形」（黒の石が正方形に近い配置）は三三禁の弱点を抱えている。

```
盤面例: 黒の石が十字形に近い配置

  F  G  H  I
9     ●
8  ●  *  ●      ← *は三三禁の候補
7     ●

白は*の周辺に自分の四を作り、
黒の防御位置を*に誘導する
```

### 実践例: 序盤早々の三三禁（京都連珠会の講座より）

```
白4に対し黒5が敗着 → 白6と密集 → 黒7で四つ目に組む
白8とノリ手承知で打つ → 黒9当然 → 白10 → 黒11とさらに乗る
→ 白12の四ノビで三三禁に追い込み → 白勝ち

ポイント: 三三禁は四つ目の形の弱点
```

### 活三による三三禁誘導

白が活三を作ると、黒は両端のどちらかに石を置いて止める。その防御位置が三三禁になるように活三の方向を選ぶ。

## 四四禁の利用

### 四四禁を作る仕掛け

四四禁は中盤から終盤にかけてよく現れる。黒石が必要なことと、たいてい四追いで四四禁になることが多いため白石も必要。

```
盤面例:
    G  H  I
10  ●
9      ●
8   ●  *  ●    ← *で横と斜めの四が同時にできると四四禁
7      ●
```

### 実践例: 「カドの四々禁」（京都連珠会の講座より）

```
白14当然 → 先に白16と飛び出すのがうまい手順
→ 白18を引く → 黒19とノリ手で防ぐ
→ 四追いで四々禁に追い込み

ポイント:
- 白12の時点で黒石はまだ1つもなかった
- 慣れれば案外読みやすい形
- 手順（白16を先に飛び出す）が重要
```

## 長連禁の利用

### 長連禁を作る仕掛け

長連禁は三三禁・四四禁と異なり、黒は石を加えても根本的に解消できない。一旦長連筋ができると「負の遺産」となって黒を苦しめる。白にとっては最もおいしい禁手。

#### 長連禁の特殊な効用

- **四三を腐らせる**: 長連筋を打たせることで、黒の四三を防ぐことができる（「腐らせる」と呼ぶ）
- **新たな長連筋の作成**: 今見えている筋だけでなく、白の四ノビで新たに長連筋を作ることも可能

### 実践例: 長連禁と三三禁の二重禁（京都連珠会の講座より）

```
白8と引いて黒9が長連筋 → 早くも白有利
白18の四ノビが黒を長連に誘う絶対の一手 → 黒は長連筋に
白22は伸びないのが肝心 → 黒23とノリ手で防ぐのが最強
白26 → 黒27に石を入れる → 白28で三々禁と長連禁の二重禁

ポイント:
- 黒は長連禁を防ぐには28の一路上しかない
- しかしそこが三々禁
- どちらかには打たされるため白勝ち
```

黒の石が5個以上近い位置に並んでいる場合、白は黒に6連以上を打たせるように仕向ける。

```
盤面例:
  D  E  F  G  H  I  J
8  ●  ●  ●  ●  _  ●    ← H8 に置くと六連（長連禁）

白が H8 を防御位置にする四を作れば、黒は長連禁で防御不能
```

## 白の三三・四四の活用

白には禁手がないため、三三（2つ以上の活三の同時作成）や四四（2つ以上の四の同時作成）を自由に作れる。これは実質的に四三と同等の決め手になる。

### ノリ手利かずの三三勝ち（京都連珠会の講座より）

白独特の勝ち方。黒がA、Bの四ノビをどちらか打つと白の四ノリとなり、かつ防ぐにしてもA、Bのどちらもノリ手になるため、白の三三を防ぐことができない。

```
  F  G  H  I
9     ○
8  ○  *  ○      ← *に白を置くと横と縦に活三（三三）
7     ○
→ 黒は2方向同時に防御不可能 → 白の勝ち
→ ノリ手と共に勝ちまで決める痛快な一手
```

### ノリ手利かずの四四勝ち

四四勝ちはノリ手にかからないため、白の最強の勝ち方。

```
実践例（瑞星定石より）:
白16のミセ手に黒17とノリ手で防ぐ
→ 白18から四追いで四々勝ち
→ 白18、20で22点の四三を四々にしている

    G  H  I
10  ○
9      ○
8   ○  *  ○    ← *に白を置くと横と斜めに四（四四）
7      ○
→ 黒は2つの四を同時に防御不可能 → 白の勝ち
```

### 四三と禁点の焦点

白の四三（四々、三々）と黒の禁手が同じ場所にある場合は通常止まらない。黒は四三を防ぐためにそこに打ちたいのに、禁点のため打てない。

```
白の四三の焦点A点が黒の三三禁 → 黒はA点に打てない
→ 仕方なくB点と止めても、白CでA点が三三禁のまま
→ 黒Cと止めても白BでA点が三三禁
→ 白勝ち

注意: まれに禁点が解消して防げる場合もあるため、よく読むことが必要
```

## 「ウソの三」と否三々の利用

### ウソの三

見かけ上は活三だが、達四点がすべて禁手点のため、三として認められない形。白はこれを理解して、黒の「ウソの三」を見抜き、本当の脅威にのみ対応すればよい。

### 否三々

見かけ上は三三禁だが、相互参照（循環参照）により禁手が成立しないケース。白は否三々を正しく判定し、禁手追い込みの計画に影響しないようにする。

## 実践的な禁手追い込みの手順

### ステップ1: 禁手点の特定

盤面上で黒が打てない禁手点を特定する。黒の石が多いほど禁手点が増える。

### ステップ2: 禁手点を防御位置に設定

白の攻撃（四や活三）を設計し、黒の防御位置が禁手点になるようにする。

### ステップ3: 四追いで追い込み

白が四を連打し、防御のたびに黒を禁手点に近づける。最終的に防御位置が禁手点になれば白の勝ち。

## CPUアルゴリズムへの示唆

### 現在の実装

| 機能             | スコア                       | 条件      |
| ---------------- | ---------------------------- | --------- |
| 防御位置が禁手   | FORBIDDEN_TRAP_STRONG: 5,000 | hard のみ |
| 誘導セットアップ | FORBIDDEN_TRAP_SETUP: 1,500  | hard のみ |
| 白の三三勝ち     | FIVE 相当: 100,000           | 全難易度  |
| 白の四四勝ち     | FIVE 相当: 100,000           | 全難易度  |

### 改善の方向性

1. **禁手点マップの事前計算**: 黒の石配置から禁手点を事前に列挙し、白の候補手に反映
2. **四追いによる禁手追い込み**: VCF探索で防御位置が禁手かどうかもチェック
3. **段階的な追い込み**: 直接の禁手追い込みだけでなく、複数手かけた追い込みの検出
4. **medium難易度への展開**: 現在hardのみだが、mediumにも簡易的な禁手追い込みを追加
5. **二重禁の検出**: 三三禁と長連禁の同時狙いなど、どちらかには打たされる形の評価
6. **長連による四三の腐らせ**: 長連筋を利用して黒の四三を無効化する戦術の検出
7. **四三と禁点の焦点の評価**: 白の四三の焦点が黒の禁点と一致する場合の高評価
