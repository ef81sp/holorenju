# VCF/VCT/ミセ手/フクミ手の戦術解説

## 攻撃手法の階層

連珠の攻撃手法は、確実性の高い順に以下の階層がある:

```
五連（勝利）
  ↑
四三（同時に四と活三を作る = 防御不可能）
  ↑
VCF（四追い勝ち = 四の連続で四三に到達）
  ↑
VCT（三四連続勝ち = 三と四の組み合わせで四三に到達）
  ↑
ミセ手（次に四三を作れる手）
  ↑
フクミ手（次にVCFがある手）
  ↑
呼手（防ぎを強要しないが攻めを準備する手）
```

## 四三（しさん）

### 定義

四（止め四または活四）と活三を**同時に**作る手。相手は両方を同時に防御できないため、次の手で必ず五連が作れる。

### 具体例

```
座標表記: 天元(H8)付近の盤面

  F  G  H  I  J
8       ●        ← 天元
7    ●     ○
6       ●
5    *           ← *に黒を置くと...

G5に黒を置くと:
- 縦方向: G5-G7 で活三（両端G4,G8が空き）
- 斜め方向: G5-H6-?-? で四ができる
→ 四三で勝ち確定
```

### 重要なポイント

- 四三は連珠における最も基本的な決め手
- 黒の場合、四三を作る位置が三三禁に抵触しないか確認が必要
- 白には禁手がないため、三三も四四も自由に作れる

## VCF（Victory by Continuous Fours / 四追い勝ち）

### 定義

連続して四を打ち続け、相手が防御し続けても最終的に四三（または五連）を作れる勝ち筋。

### メカニズム

```
手順例:
1. 攻撃側が四を作る → 防御側は唯一の防御位置に置く（必須）
2. 攻撃側が別の四を作る → 防御側が止める（必須）
3. ...繰り返し...
N. 攻撃側が四三を作る → 防御不可能 → 勝ち
```

四を打たれた側は止める位置が1箇所しかないため、攻撃側が完全にコントロールできる。

### 具体例

```
盤面（H8が天元、●=黒、○=白）:

  E  F  G  H  I  J  K
10                ○
9        ●  ○  ●
8     ○  ●  ●  ●  ○
7        ○  ●
6           ●

黒のVCF:
1. E8（四: E8-F8にかけて四） → 白D8で防御
2. F6（四: F6-G7-H8-I9の斜め四） → 白J10で防御
3. F10（四三: 縦の四と横の活三） → 勝ち
```

### 特徴

- **確実性**: 相手の応手が限定されるため、100%の勝ち筋
- **計算容易性**: 探索木が小さい（各ノードで防御は1択）
- **優先度**: 局面を評価する際、まずVCFの有無を確認すべき
- **黒の注意点**: VCF途中で四四禁に抵触しないよう注意

### AI実装のポイント

- 探索深度: 8手程度で十分な場合が多い
- カウンターフォー: 防御手が同時に四を作る場合、VCFは中断される
- フクミ手との関連: 次にVCFがある手はフクミ手として高評価

## VCT（Victory by Continuous Threats / 三四連続勝ち）

### 定義

四と活三を組み合わせた連続攻撃で、相手が最善防御しても最終的に四三を作れる勝ち筋。VCFより広い概念。

### VCFとの違い

| 項目           | VCF            | VCT                      |
| -------------- | -------------- | ------------------------ |
| 使う攻撃手     | 四のみ         | 四 + 活三                |
| 防御の選択肢   | 1箇所のみ      | 活三は複数箇所で防御可能 |
| 確実性         | 確実に勝ち     | 正確な読みが必要         |
| 探索コスト     | 低い（分岐少） | 高い（分岐多）           |
| カウンター脅威 | 四のみ警戒     | 四と活三の両方を警戒     |

### メカニズム

```
VCTの手順例:
1. 攻撃側が活三を作る → 防御側が止める（2箇所から選択）
2. 攻撃側が四を作る → 防御側が止める（1箇所）
3. 攻撃側が活三を作る → 防御側が止める
4. 攻撃側が四三を作る → 勝ち
```

活三に対する防御は複数あるが、どちらを選んでも攻撃側が勝てるように組み立てるのがVCTの技術。

### カウンター脅威への対応

VCT探索では、防御手が脅威を作る場合の扱いが重要:

| 防御手の脅威     | 対応                                             |
| ---------------- | ------------------------------------------------ |
| 五連（ct=win）   | VCT不成立（防御側が即勝ち）                      |
| 四（ct=four）    | 攻撃側が応じる必要があるが、応手が脅威になりうる |
| 活三（ct=three） | 攻撃側の次手が四なら無視可能                     |

### AI実装のポイント

- 探索深度: 4手程度（深くすると計算爆発）
- 事後検証: 見つかった手順のカウンター脅威を事後的に検証するアプローチが効率的
- 終盤限定: 石数20個以上で有効化（序盤はコスト対効果が悪い）

## ミセ手

### 定義

次の1手で**四三**を作れる位置に打つ手。ミセ手を打たれた相手は、四三の焦点に先に石を置いて防御しなければならない。

### ミセ手の効用

ミセ手には以下の重要な効用がある:

1. **相手の石数を減らせる**: 三を直接引くと相手の防御石が増え、ノリ手（カウンター）にかかりやすくなる。ミセ手なら相手は四三の焦点1箇所に置くだけで済み、余計な石を増やさない
2. **防ぎによって別の筋が使える**: 相手の防御位置が決まることで、次に使える三や四のルートが変わり、攻めの選択肢が広がる
3. **石数を少なく勝てる**: 少ない石で勝つことは逆転の余地を減らす。連珠では「なるべく少ない石で勝つ」のが美しく、かつ実戦的

### 具体例

```
浦月定石からの例:
黒が三を引いていく途中で、直接三を引くとノリ手で止められる場面。
ミセ手を打つことで:
- 相手は四三の焦点に防御石を置く
- 黒は別の方向から三を引き続けられる
- 最終的に四追いで勝ちに到達
```

### 両ミセ手

2箇所で四三を狙うミセ手。相手は1箇所しか防げないため、実質的に勝ち確定。**連珠の最も基本的な勝ち方**。

```
A点でもB点でも四三が作れるミセ手:
→ 相手がA点を防いだらB点で四三
→ 相手がB点を防いだらA点で四三
```

> 「連珠は両ミセで勝つ」— 京都連珠会 初級講座

### ミセ手を使わないと失敗する例

```
黒がミセ手を使わず直接三を引いた場合:
→ 白がノリ手（防御しながら自分の三を作る手）で止める
→ 黒が引き詰まり（三を引ける場所がなくなる）
→ 引き詰まりは黒が最も避けなければならない状態
```

### AI実装のポイント

- ミセ手を打たれた場合、ミセ手の位置に先に置くことが必須防御
- 両ミセ手は活四に準じる脅威度
- 現在の実装: +1000（MISE_BONUS）
- ミセ手で石数を節約できることの戦略的価値は、スコア以上に大きい

## フクミ手

### 定義

「2回以上の四追いが発生する手」。次の手で**VCF（四追い勝ち）** がある手。ミセ手が「1回の四追いのフクミ手」とも言え、フクミ手はミセ手の上位概念。

### 特徴

- **発見の難しさ**: 一見何でもない手が強力なフクミ手になることがある。空いた空間に置くフクミ手の感覚は高段者の域
- **防御の困難さ**: フクミ手の脅威はVCF全体にわたるため、どこを止めるか判断が難しい。防ぎの選択肢が何箇所もあるのが防御側にとって厄介
- **ノリ手回避**: フクミ手の重要な効用として、白のノリ手をかわすことができる。直接三を引くとノリ手にかかる局面で、フクミ手で迂回する
- **複合フクミ**: フクミ手が複数方向にVCFを持つ場合、防御が極めて困難
- **連続フクミ**: フクミ手の連続で攻めていくのが「高速の攻め」。相手を振り切る有効な手段

### 具体例（京都連珠会の講座より）

```
浦月定石の例:
黒17とABの四追いを含む手を打つ。
- この手はCのミセ手にもなっている
- 黒17で直接C→17と三を引くと、白Dとトビ三で取られる
- フクミ手を使うことで白のノリ手をかわす
- フクミ手の本当の狙いは、遠くの剣先とつなげること

銀月定石の例:
黒15と含み手を打つ。
- 白のノリ手になる連をあらかじめ止めている
- 上辺に向かう白の剣先の牽制にもなっている
- 1手で複数の効果を持つ「筋のいい手」
```

### フクミ手の回数

- 通常は4〜5回程度の四追いが読めれば十分
- 長いものだと10回以上の四追いを含む場合もある
- 重要なのは回数ではなく、形を見て「ある」「なし」の判断ができること

### AI実装のポイント

- フクミ手の検出にはVCF探索（深度8程度）が必要
- 現在の実装: +1500（FUKUMI_BONUS）
- 相手のフクミ手の検出と防御も重要
- 「筋のいい手」の評価: ノリ手回避+牽制+連携の複合効果を持つフクミ手を高評価すべき

## 呼手（こしゅ）

### 定義

防ぎを強要しない手だが、その後の攻め（ミセ手やフクミ手）を準備する手。

### 特徴

- 即座の脅威がないため、相手に無視される可能性がある
- しかし、良い呼手は将来の攻めの基盤になる
- 活二の形成や、石の連携を強化する手が呼手になることが多い

### 攻撃の段階

```
1. 呼手で形を整える（活二の構築、石の連携）
2. 活三やミセ手で直接的な脅威を作る
3. 四追い（VCF）やVCTで決める
4. 四三で勝ち確定
```

## 攻撃の原則

### 優先順位

局面を見た時、以下の順序で攻撃手段を探す:

1. **五連が作れるか？** → 即勝ち
2. **四三が作れるか？** → 即勝ち
3. **VCFがあるか？** → 確実な勝ち
4. **VCTがあるか？** → ほぼ確実な勝ち
5. **ミセ手が打てるか？** → 強い攻撃
6. **フクミ手が打てるか？** → 間接的だが強力な攻撃
7. **呼手で形を整えるか？** → 将来の攻撃準備

### 「止め三」と「フリー二連」の法則

止め三1つとフリーの活二が2つあり、それらの伸びる方向がおおまかに揃っていれば、四三が作れる可能性が高い。この形を目指すのが中盤の基本方針。

| 呼手     | 明示的な検出なし | —                       |

### 改善の方向性

1. **呼手の評価**: 活二の方向の揃い具合を評価し、将来の四三の可能性を見積もる
2. **VCTの深度拡張**: 計算資源が許せば深度6-8まで拡張
3. **複合フクミ検出**: 複数方向のVCFを持つフクミ手にボーナス
4. **両ミセ手の評価**: 2箇所以上の四三点を持つミセ手を活四に準じて評価
