# 局面評価の考え方

## 評価の基本原則

連珠の局面評価は、攻撃力と防御力のバランスで決まる。最終的な目標は四三（または五連）を作ること。

### 評価の3要素

1. **攻撃スコア**: 自分のパターン（活三、活四、止め四等）の合計価値
2. **防御スコア**: 相手がその位置に置いた場合の脅威度
3. **位置的価値**: 中央寄り、方向性、将来性

```
総合スコア = 攻撃スコア + 防御スコア + 位置的ボーナス
盤面全体 = 自分のパターン合計 - 相手のパターン合計
```

## パターンスコアの階層

| パターン | スコア  | 説明                     |
| -------- | ------- | ------------------------ |
| 五連     | 100,000 | 勝利                     |

### スコアの設計思想

- **止め三(30) < 活二(50)**: 止め二から剣先を作るより、活二を発展させる方が有望
- **フクミ(1500) > ミセ(1000)**: VCFは四三より確実性が高い
- **VCT(8000) > 禁手追い込み(5000)**: VCTは完全な勝ち筋

## 攻撃と防御のバランス

### 防御スコアの計算

相手がある位置に置いた場合のスコアに係数を掛けて防御価値とする:

```
防御スコア = 相手のパターンスコア × 0.5
```

### 攻防の判断基準

| 状況         | 判断                                                |
| ------------ | --------------------------------------------------- |
| 自分に活四   | 攻撃（即勝ち）                                      |
| 相手に活四   | 防御不可能（負け確定）                              |
| 相手に止め四 | 必ず防御（例外: 自分の活四が先に作れる場合）        |
| 相手に活三   | 必ず防御（例外: 自分の四が先に作れる場合）          |
| 相手にミセ手 | ミセ手の位置に先着（例外: 自分のVCFが先にある場合） |
| 攻防均衡     | 攻撃価値と防御価値を比較し、高い方を選択            |

### 必須防御ルール

以下の状況では防御が最優先:

```
相手の活四    → 防御不可能（負け確定）
相手の止め四  → 止め位置に置く
相手の活三    → 両端のどちらかに置く
相手のミセ手  → ミセ手の位置に先着
```

防御を怠る手は候補から除外（スコア = -Infinity）。ただし自分が先に勝てる場合は例外。

## 序盤・中盤・終盤の評価の違い

### 序盤（〜6手）

- **重視**: 中央支配、活二の構築、方向性
- **軽視**: 即座の脅威（まだ石が少ない）
- **時間配分**: 基本時間 x 0.5（選択肢が広いため深くは読まない）

### 中盤（7〜20手）

- **重視**: 活三の構築、ミセ手・フクミ手、複合脅威
- **戦略**: 止め三1つ + 活二2つの形を目指す
- **方向の揃い**: パターンの伸びる方向がおおまかに揃っていれば四三の可能性が高い

### 終盤（20手〜）

- **重視**: VCF/VCT探索、禁手追い込み
- **特徴**: 盤面が埋まり、計算可能な勝ち筋が見つかりやすい
- **VCT有効化**: 石数20個以上で VCT探索のボーナスを適用

## カウンターフォーの評価

### 定義

相手の脅威を防御しながら、同時に自分の四を作る手。

### 評価

```
カウンターフォーのスコア = 防御スコア × 1.5
```

防御と攻撃を同時に達成するため、通常の防御手より高く評価される。

## 位置的評価

### 中央ボーナス

天元（H8）に近い位置ほど有利:

```
中央ボーナス = max(0, 7 - distance_from_center) × CENTER_BONUS
```

理由:

- 中央は展開方向が多い
- 複合脅威を作りやすい
- 盤端の制約を受けにくい

### 斜め方向ボーナス

斜め方向のパターンは縦横より +5% のボーナス:

- 斜め方向は隣接する空き点が多い
- 複合脅威を構築しやすい
- 人間プレイヤーが見落としやすい

## 思考プロセスのモデル

強いプレイヤーの思考プロセス:

### 1. 局面の把握

- 自分と相手の四・活三・活二の位置を認識
- 禁手点の位置を確認（黒番の場合）
- 前の手で何が変わったかを把握

### 2. 候補手の探索

- 必須防御があれば防御位置を特定
- 攻撃手を列挙（ミセ手、フクミ手、活三を作る手等）
- VCF/VCTがないか確認

### 3. 最適手の選択

- 候補手のスコアを比較
- 数手先の展開を読む
- 攻防のバランスを考慮して最善手を選択

## CPUアルゴリズムへの示唆

### 現在の評価関数の強み

- パターン検出が網羅的（跳びパターン含む）
- 必須防御ルールが厳密
- 難易度別の機能制限が段階的

### 改善の方向性

1. **局面の段階認識**: 序盤/中盤/終盤で評価関数の重みを動的に変更
2. **パターンの連携評価**: 近接するパターン同士の相乗効果
3. **形の効率評価**: 少ない石数で多くのパターンを生む手を高評価
4. **脅威の方向性評価**: パターンの伸びる方向が揃っているかどうか
5. **Quiescence Search**: 水平線効果への対策として、脅威のある局面では追加探索を行う
